# Salvar Implementation Plan

Sempre que você criar, gerar ou atualizar um **Plano de Implementação** (Implementation Plan) usando os artefatos do sistema durante o "Planning Mode", você deve **OBRIGATORIAMENTE**:

1. Salvar uma cópia exata desse plano como um arquivo chamado `implementation_plan.md` na raiz do projeto (`/implementation_plan.md`).
2. Fazer o commit deste arquivo no git e realizar o push para o repositório remoto no final da sua execução, garantindo que o histórico do plano seja mantido no repositório do usuário.
